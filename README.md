# 💰 Expense Tracker

A simple and user-friendly **Expense Tracker Web Application** built using HTML, CSS, and JavaScript.

This application helps users record, manage, search, and filter their daily expenses while automatically calculating total expenses, transaction count, and average expense.

## 🚀 Features

- ➕ Add new expenses
- 💰 Enter expense amount
- 📂 Select expense category
- 📅 Select expense date
- 📊 View total expenses
- 🔢 View total number of transactions
- 📈 Calculate average expense
- 🔍 Search expenses by name
- 🗂️ Filter expenses by category
- 🗑️ Delete expenses
- 💾 Store expense data using browser Local Storage
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 📂 Expense Categories

The application supports the following categories:

- Food
- Travel
- Shopping
- Bills
- Entertainment
- Other

## 📊 Dashboard Summary

The application displays:

- **Total Expenses**
- **Total Transactions**
- **Average Expense**

These values are automatically updated whenever expenses are added or deleted.

## 🔎 Search & Filter

Users can:

- Search expenses by expense name
- Filter expenses by category
- View the matching expense records in the expense history table

## 💾 Data Storage

Expense records are stored in the browser using **Local Storage**, allowing the data to remain available when the page is reopened in the same browser.
